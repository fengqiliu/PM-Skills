# 季度竞品分析

## 适用场景

- 每季度（Q1/Q2/Q3/Q4）输出一份面向管理层的完整竞品分析报告
- 产品年度战略规划前的竞争态势摸底
- 融资路演前的竞争壁垒梳理
- 新功能立项前的差异化机会验证

---

## 第一阶段：采集计划制定（第1-2周）

### 1.1 竞品范围界定

**直接竞争对手**（同赛道、同目标用户、同核心功能）
- 判断标准：用户"二选一"概率 > 40%
- 通常数量：3-5 家

**间接竞争对手**（替代方案、不同形态但满足同一用户需求）
- 判断标准：用户"迁移概率" > 15%
- 通常数量：5-8 家

**潜在进入者**（能力储备充分、尚未正面竞争）
- 来源：大厂孵化项目、融资消息、招聘 JD 分析
- 通常数量：2-3 家

**竞品分层矩阵**

```
                  核心用户重叠度
              低          中          高
          ┌──────────┬──────────┬──────────┐
    高    │  潜在进入  │  间接竞品  │  直接竞品  │
功能      ├──────────┼──────────┼──────────┤
相似度  低 │  可忽略    │  参考借鉴  │  间接竞品  │
          └──────────┴──────────┴──────────┘
```

| 商业模式拆解 | ✓ 完整 | ✓ 概要 | ✓ 概要 |

### 1.3 信息源清单（按可信度分级）

**S 级（原始、可引用）**
- 官方官网、产品文档、定价页面
- App Store / Google Play（评分、评论、版本日志）
- 招股书、年报、官方 PR 稿
- 公开 API 文档 / 技术博客

## 第三阶段：市场格局分析（第4-6周）

### 3.1 市场规模与增速

**TAM / SAM / SOM 估算**

```
TAM（Total Addressable Market）= 目标行业总规模
  数据来源：行业报告、上市公司披露

SAM（Serviceable Addressable Market）= 可服务市场
  = TAM × 我们可触达的客户比例

SOM（Serviceable Obtainable Market）= 实际可获得市场
  = SAM × 我们当前竞争力获取的份额
```

**市场增速判断矩阵**

| 市场特征 | 判断 | 战略含义 |
|---------|-----|--------|
| 增速 >30% | 高速增长期 | 抢份额优先于盈利 |
| 增速 10-30% | 稳定成长期 | 分化竞争、聚焦细分 |
| 增速 <10% | 成熟/饱和期 | 挤占份额、差异化存活 |
| 负增速 | 衰退期 | 谨慎投入、寻找转型 |

## 第四阶段：战略洞察与建议（第6-8周）

### 4.1 SWOT 交叉分析

|  | 机会（O） | 威胁（T） |
|--|---------|---------|
| **优势（S）** | **SO 策略**：利用优势抓住机会 | **ST 策略**：用优势抵御威胁 |
| **劣势（W）** | **WO 策略**：借机会弥补劣势 | **WT 策略**：规避劣势与威胁 |

### 4.2 差异化机会识别

**机会评估框架**

```
机会价值 = 用户痛点强度 × 市场规模 × 竞品缺口深度
执行可行性 = 技术成熟度 × 资源充裕度 × 时间窗口
综合优先级 = 机会价值 × 执行可行性
```

**差异化机会清单**

| 机会描述 | 用户痛点 | 竞品现状 | 我方优势 | 优先级 |
|---------|---------|---------|---------|------|
| | 强/中/弱 | 有缺口/竞争激烈 | 可做/有技术积累 | P0/P1/P2 |
