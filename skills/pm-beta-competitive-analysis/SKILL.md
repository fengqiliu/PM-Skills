# 竞品分析

系统化进行竞品信息收集、功能对比与差异化策略制定。

## 核心模块

### 1. 信息收集渠道

**官方渠道**
- 竞品官网、Product Hunt 首发页
- 官方公众号 / 官网博客
- 官方帮助文档、FAQ
- 版本更新日志（Changelog）
- 招股书 / 年报（上市公司）

**用户渠道**
- App Store / Google Play 评论区
- 知乎、微博、小红书用户讨论
- Reddit / Quora 社区讨论
- 第三方评测网站（Cnet、36kr、虎嗅）

**技术渠道**
- 竞品 APK/IPA 反编译（了解技术实现）
- 竞品网站 `BuiltWith`/`Wappalyzer` 技术分析
- 竞品域名 whois 信息
- SimilarWeb / App Annie 流量分析

**行业渠道**
- 艾瑞咨询、QuestMobile 行业报告
- 行业协会白皮书
- 天眼查 / 企查查（融资、专利、法律诉讼）
- 招聘网站 JD 分析（推断技术栈和团队规模）

**信息归档规范**
```
竞品名称：[产品名]
版本号：[最新版本]
信息来源：[URL/渠道]
收集日期：[YYYY-MM-DD]
可信度：[高/中/低]
核心发现：[3-5条要点]
```

### 2. 功能对比矩阵

**矩阵构建步骤**

Step 1：功能拆解
- 按模块一级菜单、二级功能点逐层拆分
- 使用"用户体验五要素"框架：战略层→范围层→结构层→框架层→表现层

Step 2：横向对比
- 对每个功能点标注"有/无/部分支持"
- 标注各产品的功能深度（基础/进阶/完善）
- 记录功能的入口层级（判断操作成本）

Step 3：差异化标记
- 标记"人无我有"的核心亮点功能
- 标记"人有我优"的体验优势
- 标记"人优我廉"的价格策略

**功能矩阵模板**

| 功能模块 | 功能点 | 我们的产品 | 竞品A | 竞品B | 竞品C |
|---------|--------|-----------|-------|-------|-------|
| 账号体系 | 微信登录 | ✓ | ✓ | ✗ | ✓ |
| 账号体系 | 游客模式 | ✓ | ✗ | ✓ | ✓ |
| 核心流程 | 即时通讯 | 完善 | 完善 | 基础 | 完善 |
| 核心流程 | 消息撤回 | ✓(2min) | ✓(2min) | ✗ | ✓(5min) |

**体验打分维度（1-5分）**
- 功能完备性
- 操作效率
- 界面美观
- 性能流畅度
- 稳定性

### 3. 差异化策略

**差异化分析框架**

```
差异化方向 = (用户痛点 × 未被满足程度) - (切换成本 × 已有依赖)
```

**四象限定位法**
- **人无我有**：重点宣传，建立先发优势
- **人有我精**：深挖体验细节，建立口碑
- **人精我廉**：性价比策略，适合价格敏感用户
- **人廉我联**：生态联动，提升迁移成本

**竞品防御性分析**
- 分析竞品护城河：品牌认知、网络效应、数据积累、生态锁定
- 寻找竞品薄弱点：用户抱怨最多、功能缺口、使用频率低
- 评估自身可执行性：技术可行性、资源投入、见效周期

**差异化叙事结构**
```
[行业背景/趋势]
  ↓
[用户需求本质]
  ↓
[现有方案的局限]
  ↓
[我们的差异化切入点]
  ↓
[具体功能/体验/价格优势]
  ↓
[用户价值量化]
```

### 4. 竞品周报模板

**周报结构**

```markdown
## 竞品动态周报 | [YYYY.MM.DD - YYYY.MM.DD]

### 一、本周动态摘要
[一句话总结本周最重要竞品动态]

### 二、竞品动态详情

#### 竞品A
- **版本更新**：[版本号] 更新内容
  - 新增功能：...
  - 优化改进：...
  - Bug修复：...
- **运营动作**：[营销活动/活动运营]
- **用户反馈**：[重点正面/负面评价]
- **本周评级变化**：[上升/下降/持平] + 原因

#### 竞品B
（同上结构）

### 三、本周洞察

#### 3.1 竞品策略趋势
[从本周动态提炼竞品战略方向]

#### 3.2 对我们的启示
[结合自身产品提出应对建议]

#### 3.3 重点关注
[下周需要持续跟进的动态]

### 四、附录

#### 信息来源清单
| 信息点 | 来源 | 链接 |
|--------|------|------|

#### 下周行动计划
- [ ] 行动项1
- [ ] 行动项2
```

**评级机制**
- A：战略级威胁，需立即响应
- B：功能跟进，中期规划参考
- C：保持关注，暂不需要行动
- D：无关信息，可忽略

## 使用流程

```
确定分析目标 → 选择竞品范围 → 建立监控机制
    ↓
信息收集（日常） → 周报汇总（每周） → 月度深度分析（每月）
    ↓
差异化策略输出 → 产品规划参考 → 需求优先级调整
```

## 输出规范

- 所有分析结论需标注信息来源和可信度
- 差异化策略需附带执行建议和优先级
- 周报须在每周一上午12点前完成
- 重大竞品动态需在24小时内触发告警
