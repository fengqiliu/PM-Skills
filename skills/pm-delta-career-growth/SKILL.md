# 职业成长技能

能力模型、学习路径、转型指南与晋升准备，助PM系统性规划职业发展。

## 核心能力

### 1. PM能力模型

#### 通用PM能力层级

| 级别 |  title | 核心能力 | 典型特征 |
|-----|--------|---------|---------|
| P1 |  PM助理/初级PM | 执行力、沟通、文档 | 在指导下执行任务，独立完成单点工作 |
| P2 |  初级PM | 需求分析、项目规划 | 独立负责小型项目，能处理常规问题 |
| P3 |  中级PM | 解决方案、全链路管理 | 负责中型项目，能协调多方资源 |
| P4 |  高级PM/资深PM | 战略对齐、体系搭建 | 负责大型项目或多个项目，推动流程优化 |
| P5 |  专家/总监 | 战略规划、团队建设 | 定义业务方向，培养PM团队 |

#### 各维度能力详解

**硬技能维度**：
- 需求分析：PRD撰写、需求优先级、MRD撰写
- 产品设计：原型设计、交互逻辑、用户研究
- 项目管理：WBS分解、进度跟踪、风险管理
- 数据分析：漏斗分析、A/B测试、指标体系
- 行业知识：市场洞察、竞品分析、商业模式

**软技能维度**：
- 沟通协调：跨部门沟通、干系人管理、冲突解决
- 执行推进：优先级判断、资源协调、问题解决
- 商业敏感：成本意识、ROI思维、商业谈判
- 战略思维：行业洞察、长期规划、取舍决策
- 领导力：团队激励、影响力、人才培养

#### 自评方法
- 定期（每季度）对照能力模型自评
- 收集同事/上级的360度反馈
- 记录实际工作中的成功案例和失败案例
- 识别能力短板和提升优先级

### 2. 学习路径

#### 知识体系构建

**第一阶段：基础夯实（0-1年）**
```
必学：
- 产品需求文档（PRD）写作规范
- 项目管理基础（甘特图、WBS、里程碑）
- 用户研究方法（访谈、问卷、数据分析）
- 基础数据分析（Excel/BI工具）

建议学：
- 原型设计工具（Figma/Axure）
- 敏捷开发方法（Scrum/Kanban）
- 行业基础知识（所属行业赛道）
```

**第二阶段：能力扩展（1-3年）**
```
必学：
- 跨部门沟通与协同
- 复杂项目的风险管理
- 数据驱动决策（A/B测试、漏斗分析）
- 商业分析基础（市场规模、商业模式）

建议学：
- SQL数据提取
- 增长黑客方法论
- 财务管理基础
- 领导力基础
```

**第三阶段：战略提升（3-5年）**
```
必学：
- 产品战略规划
- OKR制定与落地
- 团队管理与培养
- 商业模式创新

建议学：
- 行业深度研究
- 投资并购基础
- 组织设计
- 战略咨询方法论
```

#### 学习资源推荐

**书籍**：
- 《产品思维》- 刘飞
- 《俞军产品方法论》- 俞军
- 《启示录》- Marty Cagan
- 《精益创业》- Eric Ries
- 《Scrum敏捷项目管理》- Ken Schwaber

**课程**：
- 内部培训：公司产品/运营学院
- 外部课程：三节课、人人都是产品经理、网易云课堂
- 专业认证：PMP、NPDP、CPDA

**实践方法**：
- 参与跨部门项目拓宽视野
- 主动承担更大范围的项目
- 定期做竞品分析和行业研究
- 建立个人知识管理体系

#### 学习计划制定
```
【年度目标】
- 核心目标：今年要突破的能力项
- 量化标准：如何衡量学习成果

【季度计划】
- Q1：学习XX，完成YY
- Q2：实践ZZ，取得AA成果
- ...

【月度复盘】
- 本月完成情况
- 下月调整计划
```

### 3. 转型指南

#### 常见PM转型方向

| 转型方向 | 核心能力迁移 | 补充学习重点 | 适合人群 |
|---------|------------|------------|---------|
| 产品经理->项目经理 | 项目管理、执行推进 | 需求管理、产品思维 | 喜欢确定性、执行控 |
| 项目经理->产品经理 | 商业敏感、用户思维 | 数据分析、原型设计 | 喜欢创造性、用户导向 |
| 技术转PM | 逻辑思维、技术理解 | 产品设计、沟通协调 | 技术背景，有产品兴趣 |
| 运营转PM | 用户洞察、数据分析 | 需求分析、项目管理 | 运营背景，理解业务 |
| B端->C端 | 用户研究、增长思维 | C端产品方法、体验设计 | B端经验丰富 |
| C端->B端 | 业务理解、解决方案 | B端销售、集成思路 | C端经验丰富 |

#### 转型准备清单

**技能准备**：
- [ ] 了解目标岗位的能力要求
- [ ] 对照能力模型找到差距
- [ ] 制定学习计划填补短板
- [ ] 获得相关项目实践机会
- [ ] 准备转型案例和成果展示

**心态准备**：
- 接受转型可能带来的短期降级
- 做好从零开始的准备
- 善用原有经验作为差异化优势
- 保持耐心，转型需要时间

**机会准备**：
- 内部转型：争取内部转岗机会，或在新项目中尝试
- 外部跳槽：准备针对性简历和面试
- 创业/自由职业：积累行业人脉和口碑

#### 转型话术（面试/内部沟通）
- "我在XX方面的经验可以迁移到...场景"
- "我意识到自己在这方面的短板，所以主动学习了..."
- "这个项目让我发现了自己的优势在...方向"

### 4. 晋升准备

#### 晋升周期与规律

**常见晋升周期**：
- P1->P2：6-12个月
- P2->P3：1-2年
- P3->P4：2-3年
- P4->P5：3-5年或更久

**晋升关键因素**：
- 持续交付可衡量的成果
- 承担超出当前级别责任
- 获得上级的认可和推荐
- 有晋升名额和组织需求

#### 晋升材料准备

**晋升答辩结构**：
```
【开场】（1分钟）
- 我申请晋升到XX级别
- 我的核心优势是...

【成果展示】（5-8分钟）
- 核心项目：背景、动作、结果
- 数据说话：量化的业务价值
- 影响力：团队、公司、行业

【能力证明】（3-5分钟）
- 对应目标级别的能力要求
- 举出对应每个能力的案例

【未来规划】（2-3分钟）
- 如果晋升成功，计划做什么
- 对团队的贡献规划

【总结】（1分钟）
- 核心价值主张
- 请求支持
```

#### 晋升成果包装技巧

**STAR法则**：
- Situation：项目背景是什么
- Task：我负责什么
- Action：我做了什么（关键动作）
- Result：取得了什么结果

**数据化表达**：
- 绝对值：营收增长XX万、用户增加XX万
- 相对值：效率提升50%、成本降低30%
- 对比值：行业排名第X、超过XX%同类产品
- 里程碑：首个XX、开创XX模式

**成果归因**：
- 突出自己的贡献（不是团队分配）
- 客观呈现，不夸大
- 承认团队和上级的支持

#### 晋升失败应对
- **主动沟通**：了解晋升未通过的具体原因
- **识别差距**：是成果不够还是能力不足
- **制定计划**：明确下阶段提升方向和目标
- **争取时间**：约定下次晋升评审的时间节点
- **保持心态**：晋升失败不代表能力不行，可能是时机或名额问题

#### 晋升自检清单
- [ ] 有没有超出当前级别的成果交付
- [ ] 有没有主动承担额外责任
- [ ] 有没有培养或影响他人
- [ ] 有没有推动流程或体系优化
- [ ] 直属上级是否认可并愿意推荐
- [ ] 晋升材料是否准备充分
