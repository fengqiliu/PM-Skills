# 会议纪要生成工具

高效组织会议、生成结构化纪要、跟踪行动项闭环。

## 会议类型与纪要模板

### 常用会议类型

| 会议类型 | 频率 | 时长 | 参与角色 | 纪要重点 |
|---------|-----|------|---------|---------|
| 需求评审 | 按需 | 1-2h | PM、开发、测试 | 需求澄清、方案确认 |
| Sprint计划 | 每Sprint | 2-4h | 全团队 | Sprint目标、任务分配 |
| 每日站会 | 每日 | 15min | 开发、测试 | 进度阻塞、计划 |
| 迭代复盘 | 每迭代 | 1-2h | 全团队 | 问题分析、改进措施 |
| 技术方案评审 | 按需 | 1-2h | 开发、架构、PM | 技术可行性、风险 |
| 上线前验收 | 按需 | 30min-1h | PM、测试、开发 | 验收标准确认 |

### 常见决策类型清单

#### 需求变更决策
```markdown
**决策类型**：需求变更
**触发条件**：开发过程中发现需求不清晰/不可行

**决策要点**：
- 是否变更需求范围？
- 变更是否影响当前Sprint？
- 是否需要额外资源？

**决策人**：产品负责人
**决策时效**：需在 24h 内决策
```

#### 技术方案决策
```markdown
**决策类型**：技术方案
**触发条件**：存在多个技术实现方案

**决策要点**：
- 各方案优缺点对比
- 长期维护成本
- 团队技术储备

**决策人**：技术负责人/架构师
**决策时效**：需在 48h 内决策
```

#### 优先级调整决策
```markdown
**决策类型**：优先级调整
**触发条件**：紧急需求插入/资源冲突

**决策要点**：
- 被挤压的需求有哪些？
- 调整对整体计划的影响？
- 如何补偿被延后的需求方？

**决策人**：产品负责人 + 项目经理
**决策时效**：需在 12h 内决策
```

## 会议效率提升指南

### 会前准备清单
- [ ] 确定会议目标和议程（提前24h发出）
- [ ] 确认参与人名单及其角色
- [ ] 准备相关材料（文档、图表、数据）
- [ ] 预约会议室/线上会议
- [ ] 提前发送邀请及预习材料

### 会中控制清单
- [ ] 准时开始，准时结束
- [ ] 记录人明确，实时记录
- [ ] 控制在议程时间内
- [ ] 结论当场确认，避免歧义
- [ ] 行动项明确到人和截止日期

### 会后跟进清单
- [ ] 24h内发出会议纪要
- [ ] 更新行动项跟踪表
- [ ] 建立定期回顾机制
- [ ] 识别重复会议，简化流程
