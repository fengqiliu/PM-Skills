# 向上管理技能

汇报节奏、资源争取、预期管理与决策支持，助PM建立健康的上下级协作关系。

## 核心能力

### 1. 汇报节奏与方式

#### 汇报原则

**金字塔汇报法**：
- 结论先行：先说结论，再说过程
- 以上统下：结论统帅论据，论据支撑结论
- 归类分组：同类信息合并，控制在3点以内
- 逻辑递进：按重要程度或时间顺序排列

**汇报时间分配**：
```
结论：10%
数据/论据：50%
后续计划：20%
请求支持：20%
```

#### 汇报频率与形式

| 场景 | 汇报频率 | 形式 | 时长 |
|-----|---------|------|------|
| 日常进展 | 每周1次 | 周报/周会 | 15-30min |
| 里程碑节点 | 按需 | 专项汇报 | 30-60min |
| 突发问题 | 即时 | 口头/消息 | 5min内 |
| 阶段总结 | 每月 | 书面+口头 | 20-40min |
| 年度汇报 | 每年 | 正式汇报 | 按公司要求 |

#### 领导类型与沟通策略

| 领导类型 | 特征 | 沟通策略 |
|---------|------|---------|
| 决策型 | 关注结果和效率 | 结论先行，准备好选择题 |
| 细节型 | 关注过程和数据 | 准备好详细数据和备选方案 |
| 授权型 | 关注目标和结果 | 定期同步，主动汇报风险 |
| 表达型 | 关注想法和创新 | 多提方案，让他做选择题 |
| 谨慎型 | 关注风险和控制 | 强调风险缓解措施和Plan B |

#### 汇报内容分层

**给CXO/高管**：
- 只说重点（1-3个核心信息）
- 关注战略价值和商业影响
- 用数据说话，避免过多细节
- 附带明确的支持请求

**给直接上级**：
- 完整的背景、问题、方案
- 风险预警和需要的支持
- 完整的选项分析（利弊权衡）
- 执行层面的落地难点

### 2. 资源争取

#### 资源争取框架

**准备阶段**：
- 明确需要什么资源（人、钱、时间、权限）
- 量化资源投入的预期回报
- 准备替代方案（如果争取不到全额）
- 了解领导的关注点和决策标准

**说服结构**：
```
【背景】
- 项目背景和当前状态
- 为什么要争取这个资源

【价值】
- 投入产出比（ROI）
- 战略重要性
- 不投入的风险/机会成本

【方案】
- 具体资源需求
- 使用计划
- 预期成果

【备选】
- 如果争取不到全额，是否有替代方案
- 最低可用资源的边界
```

#### 资源争取话术

**开口时机**：
- 领导主动问"有什么需要支持的"
- 项目关键节点刚取得成果
- 年度预算规划期
- 其他部门刚获批资源

**常用话术**：
- "为了达成XX目标，我们需要在XX方面投入...预计可以带来..."
- "目前的资源只能支撑到...，如果不追加可能会影响..."
- "我理解预算紧张，我准备了A/B两个方案，A方案是全额...B方案是缩减到...但效果会打折扣..."
- "别的项目在XX方面有类似投入，效果是...我们可以参考..."

#### 常见资源类型与争取策略

| 资源类型 | 争取策略 |
|---------|---------|
| 人力 | 用数据证明工作量，展示自动化/外包替代方案 |
| 预算 | 计算投入产出比，对标行业标准 |
| 时间 | 展示赶工成本vs延期损失的对比 |
| 权限/通道 | 说明业务价值，承诺结果担当 |

### 3. 预期管理

#### 预期管理四步法

**Step 1：共识目标**
- 明确量化的成功标准（KPI/OKR）
- 确认双方对"完成"的定义一致
- 书面记录并让领导确认

**Step 2：分阶段同步**
- 将大目标拆解为小里程碑
- 每个里程碑主动汇报进展
- 偏差超出阈值时提前预警

**Step 3：管理风险预期**
- 识别可能的风险点和延期因素
- 主动暴露问题，不要等到不可收拾
- 提出风险缓解措施和备选方案

**Step 4：调整与确认**
- 外部环境变化时及时同步
- 提供多个调整方案供领导选择
- 重大变更需要书面确认

#### 预期管理常见场景

| 场景 | 不要说 | 应该说 |
|-----|-------|-------|
| 进度延期 | "快了快了，马上就好" | "原计划XX完成，目前delay到XX，主要原因是XX，我们正在..." |
| 范围缩减 | "都能做，没问题" | "基于当前资源，我们优先保证核心功能，XX功能放到下期" |
| 效果不达预期 | "市场不行/竞品太强" | "目前数据是XX，与预期差距是XX，原因分析是XX，后续计划是..." |
| 资源不足 | "再做下去要累死了" | "按目前资源只能支撑到XX，建议XX方案..." |

#### 预警机制
- **黄色预警**：偏差达到计划的80%，需要关注
- **橙色预警**：偏差达到计划的50%，需要干预
- **红色预警**：无法按计划完成，需要决策

### 4. 决策支持

#### 给领导做决策的正确姿势

**决策类型分类**：

| 决策类型 | 领导期望 | PM准备内容 |
|---------|---------|-----------|
| 判断题 | Yes/No | 提供背景、风险、建议 |
| 选择题 | 选A/B/C | 提供选项、利弊、建议 |
| 开放题 | 提出方案 | 提供多个方案和推荐 |

**决策支持材料结构**：
```
【背景】
- 发生了什么
- 为什么需要决策

【现状分析】
- 当前情况
- 主要问题/机会点

【方案选项】
- 方案A：...
  - 优点：...
  - 缺点：...
- 方案B：...
  - 优点：...
  - 缺点：...

【建议】
- 推荐方案：X
- 理由：...
- 风险：...
```

#### 推动决策的技巧

**避免决策拖延**：
- 设定决策deadline并告知领导
- 说明延迟决策的成本
- 提供临时过渡方案

**推动保守型领导**：
- 用数据说话，减少不确定性感知
- 先在小范围试点，降低决策风险
- 引入外部对标案例作为参考

**应对推翻决策**：
- 了解推翻的真实原因（信息变了？立场变了？）
- 重新提供决策支持材料
- 尊重最终决策，但保留自己的专业判断

#### 决策记录与复盘
- 记录每次决策的背景、参与人、最终决定
- 定期复盘决策质量
- 积累决策案例库，形成组织资产
