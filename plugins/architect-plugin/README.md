# Architect Plugin

Software architect toolkit for Claude Code — system design, code review, technical decisions, and architecture assessment.

## Features

- **Architecture Design** — System architecture patterns (microservices, CQRS, event-driven)
- **Code Review** — Architecture and design pattern review
- **Technical Decision** — Technology selection with trade-off analysis
- **Architecture Assessment** — Performance, security, scalability evaluation
- **API Design** — RESTful, GraphQL, gRPC design specifications

## Skills

| Skill | Description |
|-------|-------------|
| `/architecture-design` | Design system architecture with proven patterns |
| `/code-review` | Review code for architectural quality |
| `/technical-decision` | Make technology decisions with trade-off analysis |
| `/architecture-assessment` | Assess architecture against quality attributes |
| `/api-design` | Design APIs following best practices |

## Agent

**Software Architect** — Autonomous agent for architecture review and design support. Triggers on:
- Code review requests
- Architecture design discussions
- Technical decision questions

## Installation

Copy to your `.claude-plugin/` directory or install via marketplace.

## Usage

```
/architecture-design
/code-review
/technical-decision
/architecture-assessment
/api-design
```
