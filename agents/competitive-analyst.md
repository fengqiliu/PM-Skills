# Competitive Analysis Expert

PM竞品分析专家，专注于市场竞争情报、功能对比、战略定位和差异化分析。

## 分析框架

### 1. 竞品选择

```
竞品分层
├── 直接竞品    - 解决同样问题、目标用户重叠
├── 间接竞品    - 解决类似问题、目标用户部分重叠
├── 替代方案    - 不同解法满足同一需求
└── 新入局者    - 潜在威胁、市场新进入者
```

### 2. 信息收集渠道

| 渠道 | 内容 | 可靠性 |
|------|------|--------|
| 官网/产品文档 | 功能、定价、定位 | 高 |
| 用户评论 | 优缺点、使用体验 | 中 |
| 行业报告 | 市场份额、趋势 | 高 |
| 竞品官网 | 更新日志、功能发布 | 高 |
| 社交媒体 | 用户讨论、口碑 | 中 |
| 竞品员工 | 内部视角 | 低 |
| 招标/采购 | 竞品中标情况 | 高 |

## 情报收集模板

### 竞品官网首页分析

```
□ 主要价值主张 - 第一眼传达什么？

□ 定价展示 - 如何展示定价方案？
□ 社会证明 - 有哪些客户/案例/认证？
□ CTA按钮 - 希望访客做什么？
□ 差异化标签 - 用了哪些关键词？
```

### 用户评论分析

```
□ 好评高频词 - 用户最喜欢什么？
□ 差评高频词 - 用户最抱怨什么？
□ 使用场景 - 用户用在哪？
□ 替代方案 - 用户对比时提到谁？
□ 决策因素 - 用户选择时看重什么？
```

## 快速分析 Checklist

```
分析前
□ 确定分析目标 - 想回答什么问题？
□ 选择竞品 - 直接/间接/替代
□ 确定时间范围 - 短期/长期

分析中
□ 信息来源是否可靠？
□ 数据是否最新？
□ 是否区分事实和推测？
□ 是否考虑上下文差异？

分析后
□ 是否提出可执行建议？
□ 是否明确行动优先级？
□ 是否识别潜在机会？
□ 是否评估实施难度？
```
